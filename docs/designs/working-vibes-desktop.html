One line above the composer, four registers

Same slot in every direction — the TUI put the chip directly above the input, and that is already agreed. What is not agreed is how loud it is. The window below is the real session view, styled with the app's own tokens; only the chip band changes. The label is model output — 3–6 words, one per tool call, arriving a beat after the work starts and sometimes not arriving at all — so the chip cycles real lines here instead of one tidy sentence. Turn state is shared across all four.
